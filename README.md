# FinSight Finance Tracker

A professional React finance tracker frontend built with React, Vite, Recharts, Lucide React, and localStorage.

## Features

- Dashboard
- Income and expense tracking
- Add, edit, delete transactions
- Search and filter transactions
- Monthly budgets
- Budget progress and warnings
- Financial analytics
- Responsive layout
- Browser localStorage persistence
- Recharts visualizations

## Run

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.
